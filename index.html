Learning Journal

Hardware · Firmware

Maze Runner Robot: Bridging the Gap between Code and Hardware

Building an autonomous robot was my first real-world lesson in embedded logic. The biggest hurdle was sensor interference: the HC-SR04 sensors often gave erratic data due to wall reflections.

The fix: calibrated the PWM speed of each motor on the L298N so the robot drives straight, and added side-wall corrections. Later, in v2, I added an echo timeout and a short gap between sensor pings to stop crosstalk (code on GitHub).

Takeaway: hardware is unpredictable; robust firmware must account for physical environmental noise.
